SQL, Python and Excel analysis of a user funnel to identify conversion rates and drop-off stages

#About the Project

This project focuses on analyzing how users move through a website signup funnel. The goal is to understand how many users reach each stage, where users leave the process, and which step needs improvement to increase conversions.
I completed this project using SQL, Excel, and Python to practice real-world product and marketing analytics.

#Funnel Flow

Visited Site → Signup Started → Details Filled → Email Verified → Purchase Completed

#The process 

- Counted the number of unique users at each stage.
- Calculated the conversion rate between every stage.
- Identified where the highest user drop-off occurred.
- Created charts to visualize the funnel.
- Suggested improvements based on the analysis.

#Results

| Stage | Users | Conversion Rate |
|-------|------:|---------------:|
| Visited Site | 200 | 100% |
| Signup Started | 150 | 75% |
| Details Filled | 96 | 64% |
| Email Verified | 52 | 54% |
| Purchase Completed | 44 | 85% |

#Key Finding
The largest drop-off happened between Signup Started and Details Filled, where 54 users left the funnel.
This suggests that users may be facing difficulty while filling in their details.


#Recommendation
To improve conversions, the signup process could be simplified by:

-To give chance for user,for specific process ,after enter into sign-in process
- Reducing unnecessary form fields
- Enabling autofill where possible
- Improving page loading speed
- Making the form easier to complete on mobile devices

These changes may help more users move to the next stage and complete the purchase.
